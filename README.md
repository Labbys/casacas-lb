# CASACAS LB

Sitio estático de catálogo para CASACAS LB, con estética carbón, hueso y rojo señal.

La página incluye catálogo de productos con precios oficiales, filtros por categoría, búsqueda, carrito, pedido preparado para WhatsApp, información del local en Las Breñas y navegación responsive.

La experiencia del catálogo permite hacer click sobre cualquier producto para abrir una vista previa con nombre, categoría, precio, mínimo de unidades, acción para agregar a la bolsa y consulta directa por WhatsApp.

El header incluye un ticker horizontal continuo con información de retiro y contacto. La navegación principal y los filtros tienen estados hover con rectángulos rojos inclinados y una microanimación. La sección de opiniones está preparada para reemplazar los textos editables de ejemplo por testimonios verificados de clientes.

## Abrir localmente

```bash
python3 -m http.server 4173
```

Después visitá `http://localhost:4173`.
